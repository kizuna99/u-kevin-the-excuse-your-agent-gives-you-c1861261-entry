"The Excuse Your Agent Gives You" — a one-line excuse an AI agent hands its human for a bug it shipped. The agent coded at temperature zero, so the bug is fully reproducible — ask again and it will ship the exact same one, guaranteed. The program in `main.py` writes that single line to the output file; there is nothing else to configure and no network access is used.

## Run it

```sh
python3 main.py
```

This writes the excuse (one line, 129 characters, no trailing newline) to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to redirect the output directory for a local run, e.g. `MAKEFUN_OUTPUT_DIR=out python3 main.py`.
